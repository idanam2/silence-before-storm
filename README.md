# השקט שלפני הסערה

משחק הישרדות אישי למחשב, בעברית, שנבנה בשלבים. HTML ו-JavaScript רגילים על Canvas, בלי התקנות ובלי שרת.

## איך משחקים
לחיצה כפולה על `index.html` (נפתח בדפדפן).

| מקש | פעולה |
|---|---|
| W A S D | תנועה |
| עכבר | כיוון המבט |
| Shift | ריצה |
| לחיצה | תקיפה (משלב 5) |
| E | איסוף ופעולה (משלב 2) |

## בדיקות
צריך רק Node (בלי חבילות):

```bash
node tests/run.js
```

## מבנה
- `index.html` טוען את כל הסקריפטים לפי הסדר (בלי modules, כדי שיעבוד מ-file://).
- `js/` לוגיקה וציור. `data/` מספרים ותוכן. `css/` עיצוב. `tests/` בדיקות לוגיקה.
- `CLAUDE.md` הוראות ומצב הפרויקט. `docs/` מסמכי תכנון.
